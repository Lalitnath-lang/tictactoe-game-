6x6 TIC TAC TOE PROJECT
========================

Files:
- index.html       Web interface
- style.css        Web styling
- game.js          Web game logic
- tic_tac_toe.c    C language console game

GAME RULES
----------
- 6 x 6 board
- 2 players: X and O
- Connect 4 consecutive symbols to win
- Horizontal, vertical and diagonal wins
- Draw when all 36 cells are occupied

RUN WEB VERSION
---------------
Open index.html in a web browser.

RUN C VERSION
-------------
GCC:
    gcc tic_tac_toe.c -o tic_tac_toe

Windows:
    tic_tac_toe.exe

Linux/macOS:
    ./tic_tac_toe

PROJECT TYPE
------------
College C Programming / Minor Project
